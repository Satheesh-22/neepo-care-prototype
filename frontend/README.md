# Frontend Boundary

The React/PWA application is intentionally not generated during pre-development Phases 1–10.

Member 3 must start on `feature/frontend-pwa`, read `docs/claude/MEMBER_3_FRONTEND_START.md`, present the Milestone 1 design and wait for approval before scaffolding Vite.

When the frontend application exists, add its Dockerfile and Compose service in the same reviewed milestone. Until then, `docker compose up postgres redis backend` is the supported foundation command.
